# SerTemp H01's Proprietary Service Template
Hi, I am Harihar Nautiyal founder of H01. I am making this template for future services and products by h01. It uses docker and traefik with some boilerplate rust code to make a robust framework for services in production. 

## Why?
Today making a service or product is far easier then deploying it in production. This template insures proper scaling opportunities for 
rust based web services to be deployed easily.

## Getting Started
This template is outcome of active research done by me about scaling a service and docker itself. I am not that familiar with docker but
yea, I had worked with it and I am confident I can make something which will be helpful in future deployments.
